## 📌 About the Project

IronFit Fitness Studio is a modern frontend website designed for a fitness and gym business.

The website provides information about gym programs, trainers, memberships, testimonials, contact details, and other important information through a responsive and interactive user interface.

This project was built as a frontend portfolio project to practice HTML, CSS, responsive web design, and JavaScript.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Sticky navigation bar
- Mobile hamburger menu
- Smooth scrolling navigation
- Hero section
- About section
- Fitness programs section
- Trainer section
- Results/statistics section
- Testimonials section
- Membership/pricing section
- FAQ accordion
- Gym image gallery
- Contact form with client-side validation
- WhatsApp integration
- Google Maps integration
- Scroll animations
- Responsive footer
